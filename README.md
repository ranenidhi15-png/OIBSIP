# EDA on Retail Sales Data

## Internship
OASIS INFOBYTE – Data Analytics Internship

## Task
Level 1 – Task 1: EDA on Retail Sales Data

## Objective
Perform Exploratory Data Analysis on a retail sales dataset to identify
sales trends, customer behaviour, product performance, and useful business insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Retail Sales Dataset containing information about:
- Transaction ID
- Date
- Gender
- Age
- Age Group
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed
1. Dataset inspection
2. Missing value analysis
3. Descriptive statistics
4. Mean, Median, Mode and Standard Deviation
5. Monthly sales trend
6. Quarterly sales trend
7. Age group distribution
8. Gender distribution
9. Top-selling product categories
10. Revenue by product category
11. Correlation heatmap
12. Additional gender-wise sales analysis

## Key Business Recommendations
- Maintain sufficient inventory for high-demand categories.
- Use sales trends for better promotion and inventory planning.
- Create targeted marketing campaigns using customer demographics.
- Focus on high-revenue categories and improve lower-performing categories.
